# Virat & Anushka Wedding Invitation

Static copy of https://utsav.joyinvite.in/ for GitHub Pages. Artwork remains embedded in the page; background music and all referenced font files are stored locally under `assets/`.

## Publish on GitHub Pages

1. Push this folder to a GitHub repository.
2. In **Settings → Pages**, choose **Deploy from a branch**.
3. Select the branch and `/ (root)` folder, then save.
